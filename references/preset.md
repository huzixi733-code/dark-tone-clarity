# 暗调清晰质感 · 预设参数与映射逻辑

本文件记录 `scripts/apply_style.py` 的默认配方，方便日后调参或对齐参考图。

## 预设参数（量纲 -100 ~ +100）

| 参数 | 预设值 | 缩放系数 `_SCALE` | 映射到的运算 |
|------|--------|-------------------|--------------|
| exposure 曝光 | -23 | 1.5 (EV) | `× 2^(v/100·1.5·intensity)` |
| temperature 色温 | -10 | 0.08 | 负值=偏冷：R×(1+t)、B×(1−t)，t=v/100·0.08 |
| highlights 高光 | +34 | 0.30 | 亮部掩码内 `+ hl·0.30·intensity`（提亮） |
| shadows 阴影 | -16 | 0.30 | 暗部掩码内 `+ sh·0.30·intensity`（负值=压暗） |
| blacks 黑点 | +10 | 0.15 | `× (1−floor) + floor`，floor=max(0, v/100·0.15) |
| contrast 对比度 | +42 | 0.70 | `(x−0.5)·(1+v/100·0.70) + 0.5` |
| vibrance 鲜明度 | -48 | 1.0 | 保中性：`mult = 1 − (−v)·S`，S 为逐像素饱和度 |
| saturation 饱和度 | -25 | 1.0 | `L + (x−L)·(1 + v/100)` |
| clarity 清晰度 | +65 | 1.0 | 大半径高斯得低频，`L + (L−blur)·v/100` |
| sharpness 锐度 | +35 | 1.0 | 小半径 USM：`x + (x−blur)·v/100` |

`intensity`（默认 1.0，0~1）会乘到所有调整量上，作为整体强度总开关。

## 掩码定义

- 高光掩码：`m_h = clamp((L−0.5)/0.5,0,1)²`，亮处趋近于 1。
- 阴影掩码：`m_s = clamp((0.5−L)/0.5,0,1)²`，暗处趋近于 1。
- 亮度 `L` 采用 Rec.709：`0.2126R + 0.7152G + 0.0722B`。

## 半径自适应

- 清晰度模糊半径：`max(8, min(80, max_dim/25))`，约 36px@900、80px@2000。
- 锐化模糊半径：`max(1, round(max_dim/1000))`，约 1px@1000。

## 调参方向速查

- 更暗更狠：降 `exposure`、升 `contrast`。
- 更强质感：升 `clarity`（局部对比，风格核心）。
- 色彩太灰：把 `vibrance`/`saturation` 往 0 回调。
- 更冷/更暖：调 `temperature`（负=冷，正=暖）。
- 边缘发虚：升 `sharpness`。
- 暗部死黑：升 `blacks` 微抬黑点。
